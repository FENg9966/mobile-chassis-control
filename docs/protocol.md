# ESP32-S3与STM32H743通信协议

物理层：UART 115200、8N1；ESP32-S3默认GPIO17发送、GPIO18接收；H743默认
使用USART2的PA3接收、PA2发送；两板必须共地。

每帧固定18字节，小端序，结构如下：

| 偏移 | 长度 | 字段 | 说明 |
|---:|---:|---|---|
| 0 | 2 | magic | `0xA55A` |
| 2 | 1 | version | `1` |
| 3 | 1 | type | `1`命令，`2`ACK，`3`遥测 |
| 4 | 2 | sequence | 递增序号 |
| 6 | 1 | command | 0停止、1前进、2后退、3左转、4右转 |
| 7 | 1 | speed_percent | 0～100 |
| 8 | 2 | left_rpm | 左轮转速，暂为0 |
| 10 | 2 | right_rpm | 右轮转速，暂为0 |
| 12 | 2 | battery_mv | 电池毫伏值，暂为0 |
| 14 | 2 | status | 状态位 |
| 16 | 2 | crc16 | CRC16-CCITT |

CRC参数：初值 `0xFFFF`、多项式 `0x1021`、计算时先将帧内CRC字段清零。

状态位：

- bit0：通信在线；
- bit1：急停有效；
- bit2：检测到障碍或避障停车仍在锁存；
- bit3：驱动故障，当前BTS7960版本暂未采集；
- bit4：低电量，当前ADC暂未实现。

ESP32-S3底盘桥接程序与本目录使用同一18字节结构和CRC算法。H743连续
300 ms未收到有效命令帧时会立即停止电机并抱闸。
