# 验证记录与进度

记录日期：2026-10-05。只区分当前可核对的成果与待测试项目，不用规划值替代实测指标。

## 已核对

1. 固件实际编译入口使用ST7796、FT6336及LVGL界面文件；依赖锁定版本为LVGL 8.3.11。
2. 当前屏幕照片反馈显示方向按钮、停止按钮和速度滑条；显示镜像曾修正。触控坐标应在四角与按钮位置复测。
3. 源码通信结构为packed固定18字节，CRC16-CCITT初值0xFFFF、多项式0x1021；不是16字节CRC8。
4. 屏幕转接PCB两端14针映射一致，13针均无网络；当前设计规则检查结果为空数组（无报错）。
5. H743代码中的编码器转速与电池ADC遥测暂为0；不能当作已实现闭环测速。
