# ESP32-S3屏幕转接PCB

用途：手持端ESP32-S3与鸿讯35002/ST7796/FT6336U屏幕连接，维持现有固件GPIO配置。

依据：firmware/handheld/main/board.h及当前构建配置。

## 屏幕14针接口

| 屏幕针号 | 名称 | ESP32-S3 |
|---|---|---|
| 1 | VCC | 3.3V |
| 2 | GND | GND |
| 3 | CS | GPIO10 |
| 4 | RESET | GPIO14 |
| 5 | DC | GPIO9 |
| 6 | SDI/MOSI | GPIO11 |
| 7 | SCK | GPIO12 |
| 8 | LED（背光控制） | GPIO21 |
| 9 | SDO/MISO | GPIO13 |
| 10 | T_CLK/SCL | GPIO40 |
| 11 | T_CS/RST | GPIO42 |
| 12 | T_SDI/SDA | GPIO41 |
| 13 | T_SDO | 空接 |
| 14 | T_IRQ/INT | GPIO39 |

鸿讯35002数据手册V1.2注明VCC为3.3V，主排针间距2.54mm。不能直接把5V接至屏幕VCC。背光脚是控制输入，板上已有驱动电路。

## 草稿结构

- 屏幕侧：1×14、2.54mm接口，针序遵循手册；13针不接线。
- ESP侧：独立标记GPIO的接口，通过短线接开发板；开发板型号和排针间距确认后再改成插座式。
- 电源：3.3V输入、100nF与10uF去耦；实际屏幕峰值电流及ESP开发板3.3V输出能力待确认。
- SPI：本版直接连接，PCB走线与外接线保持短；现有固件20MHz。如果长线导致不稳定，后续再降低频率或增加串联匹配电阻。
- I2C：屏幕板已有上拉，本版不重复加上拉。
- 不在本板重复放置ST7796与FT6336芯片，它们已在屏幕模块上。

## 待确认

1. ESP32-S3开发板完整型号、两排引脚数量、排距、USB朝向与尺寸；本版采用短线，不设开发板插座。
2. 屏幕现有排针公母方向、针1位置；本版通过线缆连接，不直接叠插屏幕。
3. 手持端供电来源与3.3V电源实际峰值负载；需要独立稳压时增加相应电源电路。板上只有去耦，没有降压功能。
4. 外壳、板尺寸、安装孔和屏幕装配高度。

嘉立创工程：屏幕。原理图已保存，4个元件：J1/J2各1个14针接口，C1=100nF、C2=10uF（0805）。J1、J2针号一一对应，13号两端均留空；J2按上表分别接ESP32-S3。

## PCB与配套

- PCB尺寸55.88×45.72mm，双层，4个3.2mm安装孔（临时位置，可按外壳调整）。
- J1/J2均采用1×14、2.54mm通孔排针封装，立创编号C2894937，配合母头线缆。不要将J2当作ESP开发板原始排针顺序。
- C1=100nF/0805（C49678），C2=10uF/0805（C15850），各1颗。
- 需要匹配的14针屏幕线缆，以及接ESP GPIO的短线；总线按标记连接，13号无需线。
- 3.3V电源和地沿接口进入；本板不含稳压器、电池充电或保护电路。不要直接接5V或24V。
- 尽量沿用目前已成功工作的短线长度。底层设置GND覆铜区域；生产前重新覆铜并检查DRC。
